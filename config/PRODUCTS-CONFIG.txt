================================================================================
PRODUCT CATALOG — Option B (member-app is source of truth)
================================================================================

DO NOT edit this file for day-to-day changes.

Edit catalog in moja-member-app:
  data/shop-catalog.products.json
  data/shop-catalog.layout.json

Put images in:
  moja-sites/public/images/products/

After editing member-app data, refresh this fallback snapshot:
  cd moja-sites && npm run catalog:pull

The live site loads from the Member API when MEMBER_API_BASE_URL is set.
This JSON file is used only when the API is unavailable or at static build time.

See: moja-member-app/docs/shop-catalog.md
     moja-sites/docs/deploy-mojamaison.md
